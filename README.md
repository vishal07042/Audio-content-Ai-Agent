# Audio Content AI Agent

Audio Content AI Agent combines script generation with Kokoro text-to-speech.

## Stack

- FastAPI backend
- React + Vite frontend
- Kokoro TTS
- Gemini-powered content generation

## Local setup

### Backend

```powershell
pip install -r requirements.txt
python main.py
```

### Frontend

```powershell
cd frontend
npm install
npm run dev
```
